## CHUNK 1: RAG pipeline multi-device install with network auto-detect

### Context
rag-gateway-mini repo on VM B1 (192.168.18.199:5200). RAG CLI pipeline (rag search + push-to-qdrant.sh) was only usable on one PC due to hardcoded localhost URL and no install automation.

### Problem
New devices had no way to set up the RAG pipeline without manual copy-paste of scripts, hardcoded RAG_BASE_URL=localhost:5200 in ~/scripts/rag broke on any non-local device, and no install guide existed.

### Solution
Added 4 files to repo: scripts/rag (moved from ~/scripts, RAG_BASE_URL now auto-detects via curl probe), install.sh (one-command setup), Makefile (make install/update/check), scripts/claude-mcp-connect.ps1.template. New device setup: git clone + bash install.sh. RAG_BASE_URL resolves: env var -> ~/.config/rag-gateway.env -> curl probe localhost:5200 -> LAN 192.168.18.199:5200 -> Tailscale 100.120.249.99:5200.

### Key Facts
- scripts/rag added to repo with curl-probe network detection matching push-to-qdrant.sh pattern
- install.sh handles: ~/scripts copy, PATH setup, QDRANT_API_KEY prompt, RAG_BASE_URL config, MCP instructions
- RAG_BASE_URL priority: env var > ~/.config/rag-gateway.env > auto-detect (localhost -> LAN -> Tailscale)
- MCP for Claude Code requires manual copy of settings.json + claude-mcp-connect.ps1 (path is user-specific)
- make check runs bash install.sh --check which probes all three network paths
