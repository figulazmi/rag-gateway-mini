## CHUNK 1: Fix MCP server SCORE_THRESHOLD 0.5 to 0.35 and homelab-biased retry expansion
<!-- rag_chunk_meta chunk_type=debug tags=[homelab, vm-b1, mcp, qdrant, score-threshold, query-quality, fixed] -->

### Context
qdrant-mcp-server.js on VM B1 at /opt/mcp-servers/qdrant-knowledge/ handles search_knowledge MCP tool. It uses SCORE_THRESHOLD to filter results and a retry mechanism for low-quality queries.
### Problem
Two bugs degraded query quality: (1) SCORE_THRESHOLD=0.5 was too high for RRF fusion scores -- rag-gateway already used 0.35 after the hybrid RRF refactor, but MCP server was never updated. Borderline-relevant results (0.35-0.49) were discarded before NOT_FOUND gate could evaluate them. (2) Auto-retry expansion was hardcoded to homelab terms ("deployment configuration setup steps homelab VM B1") regardless of the requested project -- petrochina-eproc queries got homelab expansion, biasing retry results toward wrong project.
### Solution
Patched /opt/mcp-servers/qdrant-knowledge/qdrant-mcp-server.js:
- SCORE_THRESHOLD: 0.5 -> 0.35 (aligns with rag-gateway ScoreThreshold for RRF)
- RETRY_THRESHOLD: 0.6 -> 0.50 (compensate for lower avgScore with wider filter)
- Retry expansion: replaced hardcoded string with project-aware map:
  homelab -> "deployment configuration setup steps homelab VM B1 Docker infrastructure"
  petrochina-eproc -> "Blazor .NET 9 EF Core CQRS MediatR implementation pattern C#"
  fallback -> "implementation architecture system behavior"
### Key Facts
- NOT_FOUND_THRESHOLD stays at 0.50 -- it is now a meaningful quality gate (topScore below 0.50 = genuinely not found) distinct from SCORE_THRESHOLD (per-result inclusion).
- MCP server is spawned per-session via SSH stdio -- no restart needed, change takes effect on next Claude Code session.
- Patch applied via Python script: pathlib.Path.read_text / str.replace / write_text.
- File: /opt/mcp-servers/qdrant-knowledge/qdrant-mcp-server.js on VM B1 (192.168.18.199).
- rag-gateway ScoreThreshold (0.35) and MCP server SCORE_THRESHOLD (0.35) now in sync.
