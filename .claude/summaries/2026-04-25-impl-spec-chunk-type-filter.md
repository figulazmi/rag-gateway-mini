## CHUNK 1: Feature: chunk_type filter added to search_knowledge MCP tool and impl-spec trigger rules
<!-- rag_chunk_meta chunk_type=feature tags=[homelab, vm-b1, mcp, qdrant, chunk-type, implementation-spec, feature] -->

### Context
RAG pipeline on homelab uses qdrant-mcp-server.js on VM B1 to serve search_knowledge MCP tool to Claude Code. Previously the tool had no chunk_type filter, making implementation-spec chunks unretrievable on demand. Claude Code also lacked clear trigger rules for when to capture vs retrieve impl-spec type.
### Feature
Two changes implemented: (1) qdrant-mcp-server.js patched with chunk_type optional parameter. searchQdrant() signature extended with chunkType=null. If set, adds payload filter {"key": "chunk_type", "match": {"value": chunkType}} to mustFilters before hybrid RRF query. inputSchema.properties gains chunk_type field with enum of all valid types. Handler destructuring and both searchQdrant() call sites (initial + retry) updated. Log event gains chunkType field. (2) CLAUDE.md updated: project CLAUDE.md adds item 6 to auto-capture triggers (impl-spec when writing substantial new code from scratch). Global CLAUDE.md adds code-gen retrieval rule to What Requires RAG Query section.
### Key Facts
- chunk_type is optional -- omitting it returns all types (existing behavior unchanged).
- Valid enum values: implementation-spec, pattern, decision, feature, runbook, debug, reference.
- MCP server is SSH stdio spawned per-session -- schema change takes effect on next Claude Code session automatically via ToolSearch.
- impl-spec now unblocked from reranker dependency -- use explicit chunk_type filter instead of automatic reranker prioritization.
- Trigger signal for impl-spec capture: "implement X from scratch", "write Y", output has Target Files + Interfaces + Contract sections.
- Retrieval rule: code-gen tasks query chunk_type="implementation-spec" first, fall back to unfiltered if not found.
- File patched: /opt/mcp-servers/qdrant-knowledge/qdrant-mcp-server.js on VM B1 (192.168.18.199).
