## CHUNK 1: rag and rtk not found in git bash due to missing .local/bin in PATH

### Context
On Windows, Claude Code installs claude.exe, rtk.exe, and the rag wrapper (forwarding to rag_capture.py) into C:\Users\<user>\.local\bin. Git bash does NOT auto-include $HOME/.local/bin in PATH the way PowerShell picks it up from Windows User env vars.
### Problem
In git bash, rtk returned "command not found" and "rag list" / "rag add" failed with: Error: could not connect to RAG Gateway at http://localhost:5200 ... dotnet run --project src/PetroChina.Eproc.RagGateway. PowerShell worked fine. Root cause: ~/.bashrc only exported $HOME/scripts (which contained an older rag search-client hardcoded to localhost:5200) and never exported $HOME/.local/bin. Git bash therefore resolved rag to the legacy search-client script instead of the new wrapper, and rtk was invisible.
### Solution
Prepend $HOME/.local/bin to PATH in ~/.bashrc so the new wrappers win over the legacy $HOME/scripts/rag. Order matters: use prepend, not append, because both dirs contain a file named rag. Also ensure the wrapper at ~/.local/bin/rag uses py (Windows Python launcher) not python, because git bash has no python on PATH but does have /c/Windows/py.
### Key Facts
- Git bash on Windows does not inherit $HOME/.local/bin automatically; must be added manually in ~/.bashrc.
- Two distinct rag scripts exist: ~/.local/bin/rag (wrapper to rag_capture.py for draft capture) and ~/scripts/rag (legacy search-client hardcoded to localhost:5200).
- rag add / rag list / rag merge / rag clear are local-file operations under ~/scripts/.rag_drafts/ and do NOT connect to any gateway URL.
- After editing .bashrc, run "source ~/.bashrc && hash -r" or open a new terminal; hash -r clears bash cached command-path lookups.
- Wrapper must use exec py on Windows git bash; python is not on PATH, py is at /c/Windows/py.
### Code
```bash
# ~/.bashrc - prepend .local/bin so new wrappers win
export PATH="$HOME/.local/bin:$PATH"
export PATH="$PATH:/c/Users/Clandesitine/AppData/Local/Microsoft/WinGet/Links"
export PATH="$PATH:$HOME/scripts"

# ~/.local/bin/rag - wrapper using py launcher
#!/usr/bin/env bash
exec py "/c/Users/Clandesitine/source/repos/rag-gateway-mini/scripts/rag-capture-v2/rag_capture.py" "$@"
```
