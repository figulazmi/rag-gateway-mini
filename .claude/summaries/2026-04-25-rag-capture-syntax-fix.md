## CHUNK 1: rag_capture.py save_draft unterminated string literal syntax error fix

### Context
rag_capture.py is the CLI backend for the RAG incremental capture pipeline on Windows dev machine. `rag add` feeds chunks to Qdrant via n8n webhook.

### Problem
SyntaxError: unterminated string literal at line 276 inside save_draft(). A regular double-quoted string spanning multiple literal lines (without triple-quotes or \n escapes) caused the entire module to fail to import, blocking all `rag add` calls.

### Solution
Replaced the broken multi-line string literal with a single-line string using \n escape sequences:
`full_content = "{}\n\n## CHUNK {}: {}\n\n{}\n".format(frontmatter, n, meta.get('topic', ''), content)`
Verified with `python -m py_compile rag_capture.py` returning clean.

### Key Facts
- Root cause: string literal split across lines with bare newlines inside double quotes -- invalid Python syntax
- Fix: collapse to one line using \n escapes; triple-quotes would also work but single line is cleaner
- File: C:\Users\Clandesitine\scripts\rag-capture-v2\rag_capture.py, function save_draft(), formerly lines 276-281
- Symptom: ALL rag add / rag merge / rag checkpoint calls failed with import error, not just save_draft
- Verify: `python -m py_compile rag_capture.py && echo OK`
